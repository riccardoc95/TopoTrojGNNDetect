# TopoTrojGNNDetect

**Topology-Driven Explainable GNNs for Trojan Detection in Deep Learning**

---

## Overview

Deep neural networks (DNNs) are increasingly deployed in critical areas such as autonomous driving, healthcare, and finance. However, their vulnerability to adversarial threats, particularly **Trojan attacks**, raises serious security concerns. 

This repository implements **TopoTrojGNNDetect**, a novel framework that models neuron activations as graphs to detect Trojan-infected models. It combines **topological analysis** of activations with **Graph Neural Networks (GNNs)** and **Explainable AI (XAI)** techniques to ensure not only high detection performance but also interpretability of decisions.

---

## Methodology

The detection pipeline follows these key steps:

1. **Activation Extraction**: Activations are extracted from convolutional and fully connected layers of a DNN. Spatial activations are pooled to obtain compact feature vectors.

2. **Correlation Matrix Computation**: Distance correlations between activations are computed to capture structural relationships.

3. **Graph Construction**: A graph is built where neurons are nodes and edges represent strong correlations (above a threshold).

4. **GNN Training**: A GNN is trained on the generated graphs to classify models as **clean** or **Trojaned**.

5. **Explainability**: Using **GNNExplainer**, we identify the most important edges responsible for classification, enhancing trust and interpretability.

## Setup

Clone the repository and initialize the submodules:

```bash
git clone --recurse-submodules https://github.com/your-repo/TopoTrojGNNDetect.git
cd TopoTrojGNNDetect
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```
---

## How to Use

### 1. Create the Dataset

You first need to create the graph dataset from clean and Trojaned models:

```bash
python -m scripts.create_dataset --experimental_folder experiments --number_of_experiments 25
```

This command will:

- Extract activations
- Compute correlations
- Build graphs
- Save them in the `experiments/` folder.

### 2. Train the GNN

Then, train the GNN classifier:

```bash
python -m scripts.train_gnn
```

Training details (hyperparameters, optimizer settings) can be adjusted inside the `train_gnn` script.

## Experiments

The framework has been tested using **ResNet**, **VGG**, and **DenseNet** architectures. Trojaned models were generated by implanting hidden triggers during training.

**Hardware**:
- GPU: NVIDIA A100
- RAM: 128GB
- Frameworks: PyTorch, PyTorch Geometric
